<h2 align="center">🛡️ Built to survive every inbox</h2>

<table align="center">
  <tr>
    <td width="50%" valign="top">

**📐 Table-based layout**<br/>
<sub>Nested tables instead of flex or grid, the only layout every email client agrees on.</sub>

**🎨 Inline CSS**<br/>
<sub>Styles live on each element, so Gmail can't strip them.</sub>

**🪟 Outlook fixes**<br/>
<sub>`<!--[if mso]>` conditionals and VML so desktop Outlook renders correctly.</sub>

</td>
    <td width="50%" valign="top">

**📱 Responsive**<br/>
<sub>600px fluid container with a media query that stacks columns on phones.</sub>

**👁️ Preheader text**<br/>
<sub>Hidden preview line that shows next to the subject in the inbox.</sub>

**🔗 Ready for sending tools**<br/>
<sub>Merge tags like `{{unsubscribe_link}}`; images hosted on GitHub raw URLs.</sub>

</td>
  </tr>
</table>

<details>
<summary><b>🚀 How to use</b></summary>
<br/>

1. Browse them all in the [live gallery](https://mssohan.github.io/HTML-email-template/) (`index.html`), then open any `.html` file and edit the text, links and images.
2. Keep image URLs absolute, since most email clients block relative paths.
3. Paste the HTML into your sending tool (Gmail via an HTML extension, Mailchimp, Brevo, etc.).
4. Send a test to Gmail and Outlook before the real send.

</details>
